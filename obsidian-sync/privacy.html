Obsidian Sync 隐私政策

生效日期：2026-10-11。此政策适用于站点所有者个人使用的 Obsidian Sync OAuth 应用及其本机 rclone 同步配置。

用途与访问范围

应用通过 Google Drive API 读取文件名称、目录、文件元数据及同步所需的文件内容，并按使用者执行的同步操作上传、修改或删除文件。为访问现有文档，应用申请 https://www.googleapis.com/auth/drive 权限；该权限允许访问 Google Drive 文件，范围大于单个同步目录。实际同步目标由本机 rclone 命令和配置决定。

数据保存与处理

OAuth 客户端配置和授权令牌保存在使用者自己的电脑；同步文件保存在使用者选择的本机目录和 Google Drive 中。本应用没有额外的托管后台，不将文档或令牌上传到本介绍网站，不通过本应用出售数据、投放广告或训练 AI 模型。同步日志和备份可能保存在本机，由使用者管理。

第三方服务

Google 处理 Google 账号授权和 Drive 文件存储。rclone 在使用者本机执行同步。介绍网站由 GitHub Pages 托管，访问网站时可能产生由 GitHub 按其政策处理的技术日志；网站没有自定义追踪脚本或文档上传功能。Google Drive 文件内容不会为同步目的传送给 GitHub Pages。

保留、撤销与删除

文件、日志、备份及本机凭据由使用者管理和删除。可在 Google 账号的第三方连接管理中撤销 Obsidian Sync 授权。撤销授权不会自动删除既有文件或本机备份。

联系与变更

此应用仅供所有者个人使用，不开放公众账号。有关本应用的问题可通过所有者的 GitHub 页面联系；请勿公开提交授权令牌、客户端密钥或私人文档。若用途或数据处理方式改变，应先更新此政策。
